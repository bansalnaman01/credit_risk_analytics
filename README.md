# Credit Risk Analytics & Default Prediction Platform

A complete end-to-end **Credit Risk Analytics and Loan Default Prediction system** that analyzes historical loan data, builds a machine learning model to predict default risk, and presents insights through interactive Tableau dashboards to support risk-based decision making.

---

## 📌 Project Overview

Financial institutions face significant challenges in identifying high-risk borrowers early. This project focuses on analyzing loan data to improve data quality, predict loan default probability using machine learning, and generate actionable insights through data visualization.

---

## 🛠️ Tech Stack

- Python  
- SQL  
- Tableau Public  
- Jupyter Notebook  
- Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn  

---

## 📂 Dataset

- Source: Public loan dataset (Kaggle)
- Size: 10,000+ loan records
- Description: Borrower demographics, loan details, repayment status

---

## 🔍 Project Workflow

### 1. Data Cleaning & Preparation
- Handled missing values and inconsistencies
- Removed duplicates and invalid records
- Improved data accuracy by ~30%

### 2. Feature Engineering
- Created 5+ risk-related features
- Transformed raw variables into model-ready inputs

### 3. Machine Learning Model
- Built loan default prediction model using scikit-learn
- Evaluation metric: ROC-AUC
- Achieved ~78% ROC-AUC
- Generated risk scores for all customers

### 4. Visualization & Dashboards
- Created 3 interactive Tableau dashboards:
  - Loan Exposure Overview
  - High-Risk Customer Identification
  - Risk-Based Decision Support

---

## 📊 Results & Impact

- Reliable identification of high-risk borrowers
- Supports risk-based lending decisions
- Enhances credit portfolio monitoring
